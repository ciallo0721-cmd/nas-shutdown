 MiniNAS - 家庭内网NAS 使用说明
══════════════════════════════════════════

【这台笔记本第一次用】
1. 装好 Python 3 (python.org 下载, 安装时勾选 Add to PATH)
2. 双击「启动NAS.bat」(首次会自动 pip install flask)
   如果提示缺 flask, 手动执行:  pip install flask
3. 看到「MiniNAS 家庭内网NAS 已启动!」就成功了

【怎么访问】
- 笔记本本机:  浏览器打开  http://localhost/
- 其他设备(手机/电脑): 浏览器打开  http://笔记本的IP/
  查IP: 笔记本上 cmd 输入  ipconfig , 看 IPv4 地址, 比如 192.168.1.5
  → 手机直接访问 http://192.168.1.5/  (80端口, 不用打端口号)
- 防火墙首次会弹窗, 点「允许访问」

【存储规则 (就是你说那个格式)】
- C/D/E 盘根目录各建一个「NAS」文件夹 (自动建)
- 每个上传的文件存成不带后缀的「nas」文件:
    [n"test.exe"]二进制内容[ed]
- C盘写满 → 自动续写到D盘, D满 → E盘
  续块没有[n]头部, 直接是 二进制...[ed]
- 三个盘全满 → 网页上显示错误, 不会写坏文件
- 每个盘预留5MB安全空间, 不会把系统盘吃到死机

【文件索引】
- index.json 存在第一个盘的NAS文件夹里, 记录每个文件的块位置
- 如果索引丢了/坏了: 网页请求 POST /api/repair 可按时间顺序
  扫描所有 nas 文件重建索引 (按块的时间顺序拼接)

【其他】
- 支持拖拽上传、上传整个文件夹(保留目录结构)
- 删除会同时清掉所有盘上的对应存储块
- 想换端口: 打开 nas_server.py 改 PORT = 80 那行
