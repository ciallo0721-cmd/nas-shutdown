## 🧱 它是怎么工作的（技术向）

- 一台 Windows 笔记本 + Python Flask，端口 80。
- C/D/E 三个盘的 `NAS` 文件夹被合并成一块"虚拟硬盘"，存储格式为自定义的 `[n"文件名"]内容[ed]` 块。
- C 盘写满自动续 D 盘，D 满续 E 盘；三个全满会上报错误，不会写坏文件。
- 每个盘预留 5MB 安全空间，C 盘（系统盘）最多占用 100MB 兜底。
- 文件索引在 `index.json`，索引损坏可通过 `POST /api/repair` 按时间顺序扫描重建。
- 公网访问走 **Cloudflare 固定 Named Tunnel**（固定地址 `nas.ciallo0721-cmd.top`，不会因重启而变动）。
- 全站日志：所有 HTTP 请求（含恶意扫描/攻击尝试）均记录在案。
